# PF2e Line Template Fix

[English](README.md) | [Русский](README.ru.md)

Модуль для [Foundry VTT](https://foundryvtt.com/) и системы [pf2e](https://github.com/foundryvtt/pf2e): исправляет подсветку клеток у шаблона прямой (line/ray) на квадратной сетке.

## Проблема

Система pf2e переопределяет расчёт клеток только для круга и конуса; прямая проваливается в базовый алгоритм ядра — «клетка закрашивается, если её центр попал в прямоугольник луча». На диагоналях это даёт по две клетки в одном столбце и срезанные угловые клетки, что расходится с официальной диаграммой Paizo.

## Решение

Клетки определяются обходом сетки вдоль центральной линии (тонкая линия Брезенхэма — ровно одна клетка на каждый шаг ведущей оси), а длина линии считается по правилам передвижения Pathfinder 2e: диагонали чередуются 5-10-5 футов. Дополнительно:

- допуск в полклетки: линия, растянутая рукой до 29.15 фт вместо книжных 30, не теряет последнюю угловую клетку;
- направления в пределах 1° от кратного 45° приводятся к точной диагонали — дрогнувшая рука не разваливает лесенку.

Перехватывается только луч шириной в одну клетку на квадратной сетке; круг, конус, прямоугольник, гексы и широкие лучи обрабатываются как раньше.

## Совместимость

- Foundry VTT v13, система pf2e.
- Требуется [libWrapper](https://github.com/ruipin/fvtt-lib-wrapper).

## Установка

1. **Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:
   ```
   https://github.com/def-gu/pf2e-line-template-fix/releases/latest/download/module.json
   ```
3. Установите и включите модуль в настройках мира.

## Разработка

Геометрия обхода — чистая функция, покрытая тестами (включая эталонные схемы 5×3, 6×2, 4×4, 11×4, 10×5):

```
node --test test/geometry.test.mjs
```
